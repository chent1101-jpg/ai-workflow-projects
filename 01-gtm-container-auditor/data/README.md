# Data

## `sample_container.json` (committed)

Anonymized export of a real Google Tag Manager web container from a healthcare
clinic. Safe to publish. Generated by `src/anonymize.py`, which fails closed —
it will not write output if any identifying value survives verification.

Replaced: account ID, container ID, public container ID, GA4 measurement IDs,
UA property ID, first-party and vendor domains, vendor API tokens, HubSpot form
UUIDs, call-tracking client and campaign IDs, and a phone number used for
dynamic number insertion.

Preserved deliberately: the full reference graph, every tag/trigger/variable
relationship, and the *shape* of every identifier (`G-`, `UA-`, `GTM-`, phone
format). Format-based rules therefore behave identically on the public sample
and on the original — the audit findings are real, not synthetic.

## `private/anonymization_map.json` (gitignored)

The real→placeholder mapping consumed by `src/anonymize.py`. Kept out of version
control on purpose: hardcoding the map into the tool would publish exactly the
identifiers the tool exists to remove. Schema:

```json
{
  "literal": { "real-value": "placeholder" },
  "word":    { "BRAND": "PLACEHOLDER" }
}
```

`literal` keys are replaced as exact substrings, longest first. `word` keys are
replaced on word boundaries only.
